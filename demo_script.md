# 90-second walkthrough

Before recording, configure real Hindsight and run `scripts/verify_hindsight.py`. Restart the server. The memory badge shows selected configuration; successful operations demonstrate connectivity. All sample data is synthetic.

1. **Problem (15 seconds):** Open Meridian Logistics. Explain that a sales rep needs the current state of a deal after several calls, including what changed.
2. **History (15 seconds):** Load demo data. Show the latest SLA concern and the earlier ROI discussion in the timeline. Repeated loading uses stable source IDs.
3. **Comparison (25 seconds):** Click **Compare without memory**. Show the baseline and the memory-informed response. Both use the same deal metadata, but only the second uses call history. Generation paths are labeled; with Hindsight this is a workflow comparison, not a controlled same-model benchmark.
4. **Evidence (15 seconds):** Expand **Retrieved evidence**. Explain that these are returned supporting facts, not a guarantee that every generated claim is correct.
5. **Learning across deals (10 seconds):** Select Kaveri and click **Suggest tactics**. The Meridian pilot is an explicitly recorded outcome. Discuss it as a hypothesis for a new customer, not a guaranteed win.
6. **New interaction (10 seconds):** Log a synthetic update, then brief again. Show what changed and what remains uncertain.

Use a fresh bank prefix for a clean cloud recording. Do not reset or delete existing memories just to show a baseline. Review actual generated text before narrating specific claims.
