Sales agents need to remember what changed, not just what was said.

I built a deal assistant with Hindsight agent memory:

- One bank per deal keeps call histories separate.
- Retain saves notes with stable IDs for retries.
- Recall retrieves evidence before generation.
- Reflection returns a brief and supporting facts.
- A baseline comparison shows what call history adds.
- Cross-deal suggestions use explicitly recorded wins.

Synthetic data makes the workflow reproducible. Suggestions still need a rep's judgment.
